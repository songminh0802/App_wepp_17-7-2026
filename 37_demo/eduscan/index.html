Cấu hình AI (Gemini API Keys)

Thông báo quan trọng: Vì bạn đang chạy ứng dụng trực tiếp trên nền tảng thử nghiệm, hệ thống đã tự động cấp sẵn một AI nội bộ (Gemini 2.5 Flash) siêu tốc, miễn phí và không giới hạn để bạn sử dụng mượt mà nhất.
Do chính sách bảo mật của môi trường này, các API Key cá nhân sẽ bị vô hiệu hoá. Tuy nhiên, cấu hình API Key của bạn dưới đây vẫn được lưu lại và sẽ hoạt động hoàn hảo khi bạn tải file web này về và chạy trên thiết bị cá nhân!

Nhập từ 1 đến 3 API Key để hệ thống luân phiên sử dụng. Việc này giúp tránh bị giới hạn tốc độ (Rate Limit) khi tạo hoặc giải đề. (Key được lưu an toàn trên trình duyệt của máy bạn, không đẩy lên máy chủ chung)
💡 MẸO: Hãy nhập API Key 1 và bấm "Kiểm tra Key" để hệ thống tự động tải danh sách Model phù hợp.
